Clowns and Mimes

I made this for fun and community. I wanted to start a Discord server and hang out with friends now and then, so I built a game we could play together: team tag in the dark, on a torus or a Klein bottle.

It's an online multiplayer game, but it can be played offline too, against bots. That meant duplicating the bot logic in the Godot client and the TypeScript server, so a code generation step keeps the constants in sync between them. The source has both.
